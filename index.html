microSTATION Arp Controller

Program and Combination arpeggiators. Changes are live previews; nothing is written to the unit's memory unless you use Save.

Not connected

Needs Global/Media → MIDI → MIDI Filter → SysEx enabled on the keyboard, and the keyboard in Program or Combination Play mode.

Sound

↑ / ↓ step through sounds (when no field has focus). Names are the factory list; edited sounds on the unit may differ. Programs are in banks A–D and Combinations in banks A–C, 128 sounds each (A000–A127 …). Bank D of the Programs only has 96 factory sounds; D096–D127 are empty user slots. Selection uses MIDI Bank Select + Program Change, so Global/Media → MIDI → “Enable Program and Bank Change” must be on.

Joystick
X pitch bend: 0
+Y mod (CC#1): 0
−Y (CC#2): 0

Same as the realtime knobs in mode A (Cutoff, Resonance, EG Intensity, EG Release) plus the other EG knobs. Values are relative to the sound (−99…+99, 0 = as programmed), sent as MIDI CC, so the unit's current position can't be read back; they reset to 0 when the sound changes. Double-click a slider to zero it. The joystick pad sends pitch bend (X), CC#1 (up) and CC#2 (down) and snaps back to centre when released; what those do depends on the sound's joystick assignments. Needs the unit to accept control changes (Global/Media → MIDI → Enable Control Change).

Pattern

–

← / → step through patterns (when no field has focus). Presets P0–P4 are first, U-slots follow. Selecting a preset can make the unit reset Gate and Velocity, so values are re-read after every change.

This permanently overwrites a location in the keyboard's memory. The page cannot show what is currently stored there, so pick a slot you know is spare.
